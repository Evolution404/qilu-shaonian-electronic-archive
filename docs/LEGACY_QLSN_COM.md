# qlsn.com 历史站点身份与时间边界

本文件用于约束 `qlsn.com / www.qlsn.com` 的归档数据判定。**同一域名在不同年份对应的站点身份并不相同，因此禁止按域名整体批量认定为《齐鲁少年》。**

## 后期域名复用：不得批量认定

### 2014

`http://qlsn.com/webs/index.aspx` 的 2014 Wayback 快照标题为“山东省青少年活动中心 | 放飞希望的田野”，内容已变为山东省青少年活动中心网站。虽然页面出现“2013齐鲁少年澳洲游学团”等词，但这不能证明当时该域名仍是《齐鲁少年》报官网。

### 2016

`http://www.qlsn.com/Sys_Webs/News.aspx` 的 2016 快照已被垃圾 SEO/色情关键词污染，与《齐鲁少年》无关。

因此：

- 2004–2007：已通过页面正文确认是《齐鲁少年》官方站；
- 2008–2013：需要逐年、逐快照验证站点身份；
- 2014：已看到山东省青少年活动中心站点；
- 2016：存在明显被污染/劫持页面；
- `upload/newsImg/...` 等静态图片资源不得仅凭 `qlsn.com` 域名自动判定为报纸版面。

## 判定规则

`qlsn.com` 资源只有满足至少一项内容证据时，才可进入电子版主档：

1. 页面明确显示《齐鲁少年》站名并标注具体报纸期号；
2. 页面或图片本身可识别《齐鲁少年》报头、期号、版次；
3. 官方站页面明确写出“来源：齐鲁少年（XXXX期）”；
4. 与另一条独立可信来源交叉验证后可以唯一对应到具体《齐鲁少年》电子版内容。

普通站内新闻、公告、论坛、软件下载、活动照片以及域名后期复用内容不计入电子版主档。
