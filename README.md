# 《齐鲁少年》电子版历史档案（2000–）

目标：尽可能恢复 2000 年以来《齐鲁少年》（《齐鲁少年报》）的**电子版、数字报或可辨识整版扫描**记录。

## 收录标准

主档只收录能够核验为报纸电子版的材料：

- 官方/报社数字报页面；
- 原生 HTML 电子报；
- 能辨认日期、总期号、版次的整版扫描图或 PDF；
- Internet Archive 等保存的上述页面。

普通新闻转载、编辑部博客、读者回忆仅作为辅助证据，不计为电子版主记录。

## 当前已恢复年份

主档目前已有可核验电子版记录的年份：**2001、2007、2021、2023**。

其中 2007 是最新恢复的关键缺口：Wayback 保存的《齐鲁少年》官方旧站 `www.qlsn.com` 原生 HTML 页面明确标注“来源：齐鲁少年（745期）”，现已确认至少《我的同桌》《你知道1+1＞2吗》两篇。

## 已确认的数字化系统

1. **大众网旧电子报**：`https://www.dzwww.com/qilushaonian/`，栏目保留“一版、二版、三版、四版、按日期检索”。Wayback 可恢复 2001-08-03 的多篇原生电子报页面。
2. **《齐鲁少年》官方旧站**：`http://www.qlsn.com/`。2004 Wayback 页面明确写有 `WWW.QLSN.COM 版权所有: 齐鲁少年编辑部`；2006–2007 改版站包含“本报新闻、美文选登、图片、齐鲁少年报简介”等栏目，并已恢复第745期原生 HTML 文章。**注意：该域名后来发生复用，2014快照已是山东省青少年活动中心，2016还存在垃圾 SEO/被污染页面，因此必须按时间和页面内容逐条核验。**
3. **后期数字报**：`http://szb.cnssiot.cn/`。云展网的《齐鲁少年》报刊档案明确将其列为官方网站。Wayback 2022-09-28 首页快照显示系统日历下限为 2020-11-30，并可恢复 2021-12-25 的 A1–A8 版面路径。
4. **云展网静态整版镜像**：已验证《齐鲁少年》2021-12-25 A1 对应整版 JPEG 为 1200×1751，SHA-256 已写入主档。
5. `paper.cnssiot.cn` 已核验为《山东青年报》数字报，**不是《齐鲁少年》**，不纳入；`qlsn.cn / www.qlsn.cn` 已核验为“齐鲁三农网”，同样排除。

## 自动取证链

仓库现已具备自动归档研究流程：

- Wayback / Common Crawl URL 枚举；
- 旧域名与假阳性过滤；
- `qlsn.com` Wayback 快照正文身份验证；
- 高优先级电子版候选分类；
- 媒体资源 URL、尺寸、SHA-256 提取；
- 旧官网首页链接恢复、期号解析和文章批量核验。

自动化生成的候选不会直接进入主档；只有内容证据达到收录标准后才升格。

## 目录

- `data/electronic_records.csv`：已核验电子版记录
- `data/year_coverage.csv`：2000–2026 年度覆盖状态
- `data/known_systems.csv`：已确认数字报系统/域名
- `data/archive_crawl/`：Wayback/Common Crawl 原始 URL 索引
- `data/site_verification/`：旧站身份验证结果
- `data/archive_candidates/`：自动筛选的高优先级候选
- `data/legacy_recovery/`：旧官网导航、文章、期号恢复结果
- `docs/LEGACY_QLSN_COM.md`：`qlsn.com` 官方站时期与后期复用边界
- `docs/SOURCES.md`：来源与验证说明
- Issue #1：持续检索进度

> 注意：Wayback 的“抓取年份”不等于报纸“出版年份”。例如 2002/2003 抓取到的旧页面仍可能是 2001-08-03 的内容，本仓库按页面内出版时间或明确期号归档；网页发布日期也不会在没有独立证据时自动当成纸质报出版日期。
